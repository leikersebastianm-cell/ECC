Glossário simples
Shadow

Simulação com dinheiro virtual usando dados reais.

Champion

Modelo principal escolhido após validações anteriores.

Testnet

Ambiente da exchange para testar execução sem dinheiro real.

PnL

Lucro ou prejuízo acumulado.

Drawdown

Maior queda do saldo desde o ponto mais alto.

HOLD / Esperar

O modelo decidiu não entrar agora.

Kill switch

Trava que impede execução quando a segurança exige.

Threshold

Nível mínimo exigido para aceitar um sinal.
